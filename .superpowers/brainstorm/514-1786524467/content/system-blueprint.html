1Local media path

Permission grant → platform media index → metadata extraction → SQLite catalog → library and player. No cloud is required and media bytes are not uploaded.

2Online media path

Shared or browser-detected URL → server capability check → idempotent job → signed resumable transfer → checksum → local catalog.

3Optional sync path

Local outbox → authenticated sync → conflict-safe merge of playlists, progress, and preferences. Local file paths remain device-specific.

Playback never waits for cloudLocal and completed media open through the catalog even during backend outages.
Downloads are idempotentOne client job key maps to one server job; retries resume or reconcile instead of duplicating.
Failure preserves workSegments, metadata, queue position, and user intent survive restarts and network loss.
Secrets stay off screensNo API-key settings. Tokens are short-lived and stored in the platform secure store.

Cross-platform promise: Android, iOS, and Windows are first-class release targets; macOS and Linux use the same domain core after platform adapters pass parity tests. Web is a later limited client because embedded browsing, background downloads, and unrestricted local-media access cannot offer native parity. DRM bypass and downloads without user authorization are explicitly out of scope.
